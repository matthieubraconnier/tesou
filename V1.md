# V1 — Périmètre envisagé

La première version fonctionnelle de TesOu pourra explorer les espaces et
actions suivants :

- **Je pars** ;
- **Bien arrivé** ;
- **Coucou** ;
- **T’es où ?** ;
- **Je vais bien** ;
- **Journal** ;
- **Groupes** ;
- **Paramètres**.

Cette liste décrit un périmètre envisagé, pas les fondations actuelles. **Aucune
de ces fonctions métier ne doit être développée dans la présente mission.** Les
boutons visibles sur l’accueil sont uniquement des éléments de démonstration.

## Exclusions explicites

La V1 exclut :

- la surveillance permanente ;
- l’historique détaillé des déplacements ;
- le classement ou le score des proches ;
- la publicité ;
- les fonctionnalités sociales publiques ;
- la complexité inutile.
